Using gbakit (CLI & Rust Library)

Open-source, clean-room Game Boy Advance (AGB) binary format toolkit built on formatkit (0.1.10). Source: github.com/JidouGhost-TL/gbakit.

Install & Build from Source

Requires Rust 1.94.1 or newer:

git clone https://github.com/JidouGhost-TL/gbakit.git
cd gbakit
cargo build --release
cargo test --workspace

Or add gbakit as a library dependency in Cargo.toml:

[dependencies]
gbakit = { git = "https://github.com/JidouGhost-TL/gbakit" }

CLI Quick Reference

# Inspect 192-byte AGB header, complement checksum & SDK save tags
gbakit info path/to/game.gba [--json]
gbakit inspect path/to/game.gba [--json]

# Scan ROM for 32-bit AGB pointer tables (0x08000000 bus)
gbakit rom tables path/to/game.gba --min-entries 8

# Decompress GBA BIOS LZ77 (0x10) or RLE (0x30) at a ROM offset
gbakit compress decode-lz77 path/to/game.gba 0x12340 asset.bin
gbakit compress decode-rle  path/to/game.gba 0x24000 map.bin

# Create or apply IPS ROM patches
gbakit patch create original.gba modified.gba -o patch.ips
gbakit patch apply  patch.ips original.gba patched.gba

# Apply or create IPS patches, or unlock embedded debug menus
gbakit patch list-debug-menus
gbakit patch debug-menu path/to/game.gba -o debug.gba
gbakit patch apply path/to/patch.ips original.gba patched.gba
gbakit patch create original.gba modified.gba -o patch.ips

# List or verify embedded clean-room button-combo cheats (193 verified retail titles)
gbakit cheat list [--json]
gbakit cheat verify A2CE [--json]

# Probe loose .sav geometry, detect emulator padding, and identify matching game definitions
gbakit save probe mystery.sav [--json]
gbakit save info  path/to/save.sav [--json]

# Strip flat emulator padding down to canonical cartridge hardware geometry
gbakit save trim  padded.sav -o canonical.sav [--force] [--size ] [--game ]

# Verify, decode, or repair GBA battery saves (846 built-in codes or custom JSON file)
gbakit save verify AHRE path/to/save.sav
gbakit save decode AHRE path/to/save.sav
gbakit save fix    AHRE path/to/damaged.sav -o repaired.sav

# Multi-engine audio scan, export, SoundFont 2 (.sf2) & WAV write-back (13 GBA sound engines)
gbakit audio scan      path/to/game.gba [--json]
gbakit audio export    path/to/game.gba -o out_audio/ [--song <id>]
gbakit audio soundfont path/to/game.gba -o game.sf2 [--json]
gbakit audio replace   path/to/game.gba --offset 0x45678 --wav new.wav -o modded.gba [--codec pcm8|dpcm|pcm8-unsigned|ima-adpcm|ima-adpcm-arm] [--allow-relocate]

# Extract a DirectSound WaveData PCM sample to 8-bit WAV, or inspect an m4a song header
gbakit sound wav path/to/game.gba --offset 0x45678 -o sample.wav
gbakit sound m4a path/to/game.gba --song-header 0x123400

# Rip or replace 4bpp/8bpp palettes, tilesets, tilemaps & sprites, or render a single 4bpp tile to PPM
gbakit gfx rip     path/to/game.gba -o out_gfx/ [--palettes] [--tilesets] [--tilemaps] [--sprites] [--json]
gbakit gfx replace path/to/game.gba --offset 0x12340 --image sprite.png -o modded.gba [--bpp 4|8] [--palette-offset 0x10000] [--write-palette] [--allow-relocate]
gbakit gfx tile4   path/to/vram.bin --offset 0x0 --palette 0x10000 -o tile.ppm

# Text charmaps (.tbl), pointer-table string scan/extract/replace & 1bpp/2bpp VWF font sheets
gbakit text tables       [--json]
gbakit text scan         path/to/game.gba --table pokemon-gen3-en [--min-entries 10] [--json]
gbakit text extract      path/to/game.gba --offset 0x1C582D --table pokemon-gen3-en [--json]
gbakit text replace      path/to/game.gba --offset 0x1C582D --table pokemon-gen3-en --text "Custom text!" --allow-relocate -o modded.gba
gbakit text font-dump    path/to/game.gba --offset 0x200000 --count 128 --width 8 --height 16 --bpp 2 -o font.png
gbakit text font-replace path/to/game.gba --offset 0x200000 --image font.png --count 128 --width 8 --height 16 --bpp 2 -o modded.gba

# Nintendo e-Reader DotCode + vpk0 decode, encode & printable strip rendering (gba-ereader 0.1.0)
gbakit ereader decode     strip.raw -o payload.bin [--decompress]
gbakit ereader encode     payload.bin -o strip.raw [--short|--long]
gbakit ereader render     strip.raw -o card.bmp [--dpi 300|600|1200]
gbakit ereader vpk-decode data.vpk -o data.bin
gbakit ereader vpk-encode data.bin -o data.vpk [--method 0|1]

# ActImagine Mobiclip (GBA v1/v2) & GBA Video stream scan and frame/audio export (mobiclip 0.1.0)
gbakit video scan   path/to/video.gba [--json]
gbakit video export path/to/video.gba -o out_video/ [--max-frames <n>]

Rust Library Example

use gbakit::rom::{AgbHeader, scan_sdk_save_tags, scan_pointer_tables};
use gbakit::compress::{decode_lz77, DEFAULT_MAX_OUTPUT};
use gbakit::save::{verify_save, fix_checksums};
use gbakit::saves;

let header = AgbHeader::parse(&rom_bytes)?;
let tags = scan_sdk_save_tags(&rom_bytes);
let tables = scan_pointer_tables(&rom_bytes, 8);
let decompressed = decode_lz77(&rom_bytes[0x1000..], DEFAULT_MAX_OUTPUT)?;

if let Some(def) = saves::find("AHRE")? {
    let report = verify_save(&def, &sav_bytes)?;
    println!("valid: {}", report.valid);
    if !report.valid {
        let mut repaired = sav_bytes.clone();
        fix_checksums(&def, &mut repaired)?;
    }
}

  • EEPROM_8K: 8,192 bytes (64 kbit), e.g. The Legend of Zelda: The Minish Cap, Final Fantasy Tactics Advance
  • SRAM_32K: 32,768 bytes (256 kbit), battery-backed static RAM, e.g. Metroid Fusion, Castlevania: Aria of Sorrow
  • FLASH_64K: 65,536 bytes (512 kbit / 64 KiB), e.g. Pokémon Ruby / Sapphire, Super Mario Advance 4
  • FLASH_128K: 131,072 bytes (1 Mbit / 128 KiB), e.g. Pokémon Emerald, Boktai: The Sun Is in Your Hand
Many emulators pad all save dumps to a flat 64 KiB or 128 KiB file using uniform 0x00 or 0xFF fill. gbakit save inspects this geometry, identifies candidate games without requiring a game code, and strips dead padding bytes with strict safety checks. See the Cartridge Hardware & Save Geometry Guide. 
# 1. Probe an unidentified save file across all registered definitions:
gbakit save probe mystery_dump.sav [--json]

# 2. Inspect geometry, trailing padding fill byte, and slot checksum validity:
gbakit save info my_save.sav [--json]

# 3. Strip emulator padding down to canonical cartridge hardware capacity:
gbakit save trim padded_dump.sav -o canonical_save.sav [--force] [--size <bytes>] [--game <code>]

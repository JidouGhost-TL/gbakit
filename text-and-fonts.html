No Hardware Text Mode in GBA PPU: Every character on screen is drawn by game software into 4bpp (32 B/tile) or 8bpp (64 B/tile) BG tile VRAM (0x06000000) or OBJ sprite VRAM (0x06010000). Every matched title in this catalog now includes a dedicated Text, Fonts & Scene Data section on its game page.

1. The Four GBA Text & Font Architectures

  1. Fixed-Width Tilemap Fonts (ASCII, Shift-JIS, Custom .tbl): Maps character codes directly to BG screenblock tile indices (char_code - base + tile_base | (pal << 12)). Glyphs are stored as 1bpp bitmaps unpacked via BIOS SWI 0x10 (BitUnPack) or LZ77-compressed 4bpp sheets (SWI 0x11). Japanese studios frequently pack letters from a non-ASCII base (e.g. Capcom Mega Man Battle Network 'A' = 0x5F, Mega Man Zero 'A' = 0x0B, Game Freak Gen 3 'A' = 0xBB, Tactics Ogre 'A' = 0x00).
  2. Variable-Width Fonts (VWF) & Software 4bpp Blitting: Because 240×160 fits only 30 fixed 8 px columns, text-heavy RPGs store 1bpp (16 B per 8×16 glyph) or 2bpp (32–64 B per glyph with drop-shadow/outline) bitmaps alongside a per-glyph width table (flat u8[N] in Pokémon Emerald 0x633B03 / Golden Sun 0x0370B4 / FFTA 0x98D318, or linked glyph structs in Fire Emblem 0x58C76C) and shift rows across (x_px & 7) tile boundaries into 4bpp VRAM.
  3. Compressed Text (BIOS LZ77, Custom 16-bit Huffman, Bigram Huffman): Large scripts compress dialogue via BIOS LZ77 (SWI 0x11/0x12, 0x10 header), custom global 16-bit canonical Huffman trees (Fire Emblem: The Sacred Stones 2,903-node tree @ 0x15A72C), or order-1 context/bigram Huffman (Golden Sun 255-tree pointer table @ 0x029EE4).
  4. 16-Bit Custom & UTF-16LE Encodings: Unifies Latin, kana, kanji, and inline script opcodes in 16-bit code units — e.g. Metroid Fusion (0x0081 = 'A'), Mother 3 (0x00DC = 'A'), Gyakuten Saiban (16-bit script/kanji bytecode), and Gunstar Super Heroes (plain ASCII HUD @ 0x08C67F + UTF-16LE dialogue @ 0x5827D4).

4. Working with GBA Text & Fonts in gbakit

# List built-in charmaps (ascii, pokemon-gen3-en, shift-jis) or load any custom .tbl:
gbakit text tables [--json]

# Scan a ROM for string pointer tables matching a charmap:
gbakit text scan path/to/game.gba --table pokemon-gen3-en --min-entries 10 [--json]

# Extract or replace strings in-place or via 0xFF free-space relocation + pointer patching:
gbakit text extract path/to/game.gba --offset 0x1C582D --table pokemon-gen3-en
gbakit text replace path/to/game.gba --offset 0x1C582D --table pokemon-gen3-en \
  --text "Custom GBA text!" --allow-relocate -o modded.gba [--json]

# Dump or re-inject 1bpp / 2bpp bitmap & VWF font sheets as PNG/PPM:
gbakit text font-dump    path/to/game.gba --offset 0x200000 --count 128 --width 8 --height 16 --bpp 2 -o font.png
gbakit text font-replace path/to/game.gba --offset 0x200000 --image font.png --count 128 --width 8 --height 16 --bpp 2 -o modded.gba

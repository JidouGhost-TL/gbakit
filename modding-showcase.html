Auto-Patched 32-bit ROM Pointers
Non-Destructive In-Place & Relocated Write-Back: When replacement data fits inside the original asset's capacity, gbakit writes in-place with zero pointer mutations. When it grows larger, passing --allow-relocate allocates aligned 0xFF free space and automatically patches every 32-bit AGB ROM bus (0x08000000) pointer referencing the original offset.

4. Copy-Pasteable CLI Workflows

# 1. In-place 8bpp LZ77 tileset replacement (Pokemon FireRed BG0 title logo @ 0xEAB8C4):
gbakit gfx replace firered.gba --offset 0xEAB8C4 --image custom_logo.png \
  --bpp 8 --palette-offset 0xEAD4F4 -o firered_mod.gba --json

# 2. Relocated 4bpp LZ77 tileset replacement with automatic 32-bit ROM pointer patching:
gbakit gfx replace advance_wars.gba --offset 0x1374A8 --image custom_aw_logo.png \
  --bpp 4 --allow-relocate -o advance_wars_mod.gba --json

# 3. DirectSound M4A WaveData PCM8 replacement (in-place or --allow-relocate):
gbakit audio replace firered.gba --offset 0x4A741C --wav tone_880hz.wav \
  --codec pcm8 --allow-relocate -o firered_audio_mod.gba --json

# 4. VWF / charmap string replacement with 0xFF free-space relocation + pointer patching:
gbakit text replace firered.gba --offset 0x1C582D --table pokemon-gen3-en \
  --text "Modded with gbakit!\nPress A to continue." --allow-relocate -o firered_text_mod.gba --json
